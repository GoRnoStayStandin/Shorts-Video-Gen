# Shorts-Video-Gen

**Shorts-Video-Gen** — это локальный AI-инструмент для автоматизированного создания коротких клипов из длинных видеороликов.

Проект позволяет загрузить видео, распознать речь, выделить смысловые фрагменты, оценить пригодность каждого фрагмента для короткого клипа, отредактировать описание и экспортировать выбранный отрезок в отдельный MP4-файл.

Инструмент ориентирован на обработку интервью, влогов, обучающих видео, разговорных роликов и другого видеоконтента, из которого нужно быстро получить короткие фрагменты для дальнейшего использования.

---

## Возможности

- загрузка локального видеофайла через веб-интерфейс;
- извлечение аудио из видео через FFmpeg;
- распознавание речи с помощью `faster-whisper`;
- смысловая сегментация транскрипта с использованием локальной модели GPT4All;
- автоматическое формирование кандидатов на короткие клипы;
- оценка пригодности фрагментов через `score`;
- отображение найденных клипов на таймлайне;
- редактирование названия, описания и текста клипа;
- генерация SRT-субтитров для выбранного фрагмента;
- экспорт выбранного клипа в MP4;
- сохранение промежуточных результатов в JSON-файлы.

---

## Как работает система

Обработка видео выполняется поэтапно:

1. **Загрузка видео**  
   Пользователь загружает видеофайл через Streamlit-интерфейс.

2. **Извлечение аудио**  
   Из видео извлекается аудиодорожка в WAV-формате с помощью FFmpeg.

3. **Распознавание речи**  
   Аудио передается в `faster-whisper`, который формирует текстовую расшифровку с таймкодами.

4. **Смысловая сегментация**  
   ASR-сегменты передаются в GPT4All небольшими окнами. Модель выделяет смысловые подтемы и возвращает границы фрагментов.

5. **Оценка пригодности клипов**  
   Для каждого найденного фрагмента рассчитывается `score`. Оценка учитывает:
   - длительность фрагмента;
   - количество слов;
   - плотность речи;
   - наличие смысловых маркеров;
   - наличие шумовых или малополезных фраз.

6. **Редактирование результата**  
   Пользователь может изменить название, summary и текст найденного клипа.

7. **Генерация субтитров и экспорт**  
   Для выбранного клипа можно создать SRT-файл и экспортировать видеофрагмент в отдельный MP4-файл.
